# Agal journey photographs

Team-supplied photographs for `/documentation`. The chapter order and regional
championship were confirmed by the team: mentoring, regional championship,
trader interviews, farmer interviews, then ongoing travel to the semifinals in
Quezon City. Event dates and interview quotations have not been supplied.

The gallery contains 14 selected photographs. Each has a WebP preview (longest
edge at most 960px, quality 78) and a `-large.webp` version (longest edge at most
1600px, quality 85). Sharp applied EXIF orientation before resizing; photographs
were not cropped or enlarged, and embedded metadata was removed. The original
local files are the source material. The farmer-team preview is also the hero.
